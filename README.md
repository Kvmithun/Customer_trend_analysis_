# 📊 CUSTOMER BEHAVIOR DATA ANALYSIS

THIS PROJECT ANALYZES CUSTOMER SHOPPING BEHAVIOR USING **PYTHON, SQL, AND POWER BI**.

THE GOAL IS TO CLEAN AND ANALYZE CUSTOMER DATA, FIND USEFUL BUSINESS INSIGHTS, AND PRESENT THEM THROUGH AN INTERACTIVE POWER BI DASHBOARD.
